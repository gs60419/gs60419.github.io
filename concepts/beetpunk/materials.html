衍生物構想

甜菜收成後先拆成甜菜根與甜菜葉，再延伸出木頭、纖維 / 毛、石頭、礦物 / 紅石四條路線，讓甜菜能支撐 Minecraft 的早期生存與中期科技。

Split

第一個拆解

玩家收成原版甜菜後，先在背包中拆成甜菜根與甜菜葉。這一步保留原版甜菜作為熟悉入口，也讓 mod 的材料樹從同一個作物自然長出來。

甜菜葉負責木頭、纖維、布料與早期機械零件；甜菜根負責壓縮、脫水、榨油、石材與中期礦物線。

Skyblock Goal

6 格空島也能長出材料世界

衍生物路線的目標，是讓玩家即使只有極小空島、少量甜菜與非常有限的初始資源，也能逐步接近大部分原版建材體驗。

甜菜葉提供木頭與纖維感，甜菜根提供壓縮與硬質建材感，處理台把甜菜塊轉成乾塊、油、渣與水滴；後續石頭、砂、礦物 / 紅石前置則讓空島玩法不只停在農作物，而能長成一套慢速、可升級、可自動化的甜菜工業。

Routes

四大資源路線

木頭路線

甜菜葉 → 甜菜枝條 → 甜菜枝磚、甜菜工具柄、甜菜鍋。取代部分木棍、木板與早期結構材料。

纖維 / 毛路線

甜菜葉 → 甜菜纖維 → 甜菜布、甜菜濾網、甜菜繩索。支撐布料、濾材與處理台零件。

石頭路線

甜菜根 → 甜菜塊 → 甜菜乾塊 → 甜菜磚、甜菜鵝卵石、甜菜礫石、甜菜沙。

礦物 / 紅石路線

甜菜沙、甜菜渣、甜菜油進一步洗選或催化成甜菜鐵砂、甜菜紅石粉、甜菜晶粒與甜菜導線。

處理台副產物

甜菜塊 → 甜菜乾塊 + 甜菜水滴；甜菜乾塊 → 甜菜渣 + 甜菜油。

開發分期

V1 先做木頭、纖維、甜菜塊與處理台；石頭路線放 V1.5；礦物 / 紅石線放 V2。

Flow

材料流

  1. 甜菜葉合成甜菜枝條與甜菜纖維，開啟木頭與布料路線。
  2. 甜菜根壓縮成甜菜塊，是處理台與建材路線的主要輸入。
  3. 甜菜處理台把甜菜塊脫水，再把乾塊榨成甜菜渣與甜菜油。
  4. 甜菜沙連接石頭與礦物線，後續可洗選出鐵砂、紅石粉或晶粒。
