小屁論 7.3

心智界的迴圈

7.3 把迴圈語法轉進主體內部：注意力不是孤立的一點，而是由刺激、焦點與聯想構成的循環。

讀 7.3上一章 7.2下一章 7.4

Δ：刺激差異 / φ：焦點穩態 / η：聯想交換

Core Idea

注意力也是一種封閉能量迴圈

心智界讓 7.0 第一次離開物理尺度，進入人的注意力。注意力會被差異啟動，會暫時固定成焦點，也會透過聯想、語言、行動與其他念頭交換。

焦慮可以暫時讀成張力過高，走神可以讀成迴圈無法封閉，心流則像注意力進入低阻力穩態。創意爆發則可能來自兩個心智迴圈突然相位疊合。

這些不是心理學定論，而是小屁論用來整理心智動態的語法模型。它讓物質界的「封閉張力」在心智界變成「注意力如何維持或崩解」。

States

心智狀態的 7.3 讀法

焦慮

迴圈張力過高，注意力無法順利釋放或轉向。

走神

焦點無法維持，迴圈斷裂或跳到其他路徑。

心流

注意力、行動與回饋進入低阻力穩態。

創意

兩個或多個心智迴圈突然疊合，產生新差異。
