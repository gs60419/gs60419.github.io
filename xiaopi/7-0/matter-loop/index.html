小屁論 7.1

物質界的迴圈

7.1 是 7.0 的微觀樣板：粒子不是先被理解成小球，而是被讀成 360 度張力封閉環。

讀 7.1 回 7.0 下一章 7.2

粒子 = 被張力封閉後可被觀測的穩態外殼

Core Idea

最小尺度的迴圈存在者

7.1 把 7.0 的核心直覺放在物質底層：原子、費米子或夸克，也許不該先被想成具有硬邊界的小顆粒，而應該先被讀成場與張力形成的封閉外殼。

在這個語法模型裡，質量像是維持封閉狀態所需的張力，自旋像是迴圈相位，夸克則像物質迴圈裡的三段式節點。這些仍是概念模型，不是標準物理公式。

7.1 的任務，是替後面所有界層建立第一個樣板：如果物質界的基本單位可以被讀成迴圈，那其他界層是否也有相似的封閉、張力、相位與崩解模式？

Mapping

7.1 的暫定對照

粒子

closed shell

被場與張力封閉後，形成可被觀測的穩態外殼。

質量

tension to stay closed

暫時讀成維持迴圈封閉狀態的張力成本。

自旋

loop phase

暫時讀成迴圈的相位或拓樸回復條件。

夸克

three-part node

暫時讀成物質迴圈中的三段式語法節點。
