小屁論 7.8

不准向內的向量

7.8 回到 7.0 的夸克向量起點，把「360 度向外」重算成「360 度不准向內」：不是有一個中心往外推，而是某些方向沒有可維持的流路。

讀 7.8上一章 7.7前往 8.0

限制不是外加規則；限制是 Δ 分布的缺口。

Core Shift

從方向語法到缺口語法

7.0 最早的圖像是：粒子不是小球，而是一圈 360 度向外的力、向量或張力外殼。這個圖像很有力，因為它把粒子從「硬物」改成「場與張力形成的封閉結構」。

7.8 進一步追問：如果我們看到的「向外」，其實不是主動外推，而是「不能向內」造成的外顯效果呢？這一句會改變整個模型。向外語法需要一個中心、一個源頭、一個發射方向；不准向內語法則先看哪些方向無法成立，哪些路徑不能維持。

因此 7.8 的重點不是替 7.0 加一個新比喻，而是把粒子從「力的發射」改寫成「限制的顯形」。粒子不一定是某個中心往外推，而可能是一個場無法向內收斂後留下的穩定邊界。

Water Model

水流、石頭與 not-water

原本問法

水裡有多少石頭？

先假設石頭是已經存在的物，再把它放進背景裡計算。

7.8 問法

哪裡不是水？

先有水，再找出水無法繼續成為自己的穩定區域。

物件轉條件

stone = stable not-water

石頭不是先被定義的東西，而是水中一塊穩定的非水區。

粒子對應

particle = stable not-inward

粒子可以被讀成場中一塊穩定的不可向內區域。

Δ Flow

Δ 像水一樣流動

水流模型讓 7.8 更清楚：Δ 不只是正負相消的差異，而是一種會流動、會重分配、會集中或稀薄的差異密度。η 是這個差異的流動，φ 是差異暫時穩定下來後形成的河道、積水或漩渦。

Δ

水 / 差異密度

世界裡可被區分、可重新分配的差異量。

η

水流 / 重新分配

差異如何流動、分流、合流與改道。

φ

河道 / 漩渦 / 積水

差異流動後留下的穩定形狀，也會反過來限制新的流動。

缺口

流不到的地方

不是被命令禁止，而是那裡沒有可維持的 Δ 流路。

Least Action

不是被選擇，而是先流到

在這個模型裡，最小作用量也被重新閱讀。它不是宇宙先比較所有路線，再挑一條最省的路；比較像水在缺口與地形中流動，只有某些路徑能先形成、能持續，最後看起來就像被選中。

所以 7.8 的句子可以寫得很直白：不是這條路比較好，是水只能走這條路。路徑不是被選擇，路徑是剩下來的。

向外 → 不准向內；方向 → 差異；規則 → 流不到的地方；選擇 → 先形成。
