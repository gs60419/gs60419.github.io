小屁論 3.7 / Residue Theory

渣渣理論

3.7 接在語意熱力學之後，問一個更細的問題：資訊被壓縮、做功、整理之後，旁邊掉出來的殘層到底是廢料，還是下一個模型的胚芽？

讀文章 模型 三種殘層 回收流程 回 3.0

壓縮不是只產生核心種子，也會產生殘層；殘層不是全都該丟掉，其中一部分會成為下一次生成的土壤。

Start Here

不是所有沒有進入主線的東西，都是失敗

渣渣理論是一個關於「剩餘物」的思想模型。當一段對話、一批靈感或一組理論被壓縮成核心句時，最醒目的部分會被留下來，變成標題、公式、章節或命名。但壓縮不會只留下核心，它也會在旁邊掉出許多還沒被正式收編的碎片。

這些碎片可能是一句半成熟的比喻、一個還沒想完的問題、一段看似多餘的語氣、一條沒走完的分支，或是某個暫時不知道該放哪裡的直覺。一般整理法很容易把它們刪掉，因為它們沒有立刻服務目前的主線。

但小屁論 3.7 反過來問：如果它們不是沒有價值，而是還沒找到適合的軸呢？有些渣渣確實只是噪音，可以分解掉；有些渣渣則保存了重要脈絡；還有一些看起來很小，卻帶著弱動力、弱語法與跨域連結能力。

最後那一類，就是渣渣理論最在意的東西。它們不是主線的失敗，而是下一個概念還沒孵化前的殘層。

Model

壓縮會同時產生種子與殘層

壓縮函數

C = f(M, D, R)

`M` 是多域資訊，`D` 是結構密度，`R` 是關係重力。壓縮不是單純縮短，而是把不同材料拉到同一個結構裡。

種子與殘層

C -> S + AR

`S` 是核心種子，會進入主線；`AR` 是壓縮殘層，常常藏在對話邊角、刪掉的句子與未命名的直覺裡。

再生關鍵

Structure-AR -> S'

當殘層仍保有方向、關係與可展開性，它就可能從舊壓縮的副產品，變成下一次壓縮的新種子。

AR Layers

三種殘層：噪音、脈絡、結構

Noise-AR

噪音殘層 -> 分解

這類材料缺少有效結構，可能只是重複、失真或太低密度的碎片。它不需要被硬救，分解掉也是整理的一部分。

Context-AR

脈絡殘層 -> 部分回收

它未必能直接變成新理論，但能保存概念的來源、語氣、問題意識與生成現場。它很適合進入註解、版本史與前言。

Structure-AR

結構殘層 -> 再生成種子

它看起來像邊角料，裡面卻還有微動力、微向量、微語法與跨域映射能力。這是渣渣理論真正要保護的東西。

After 3.6

為什麼 3.7 要接在語意熱力學後面

3.6 語意熱力學關心語意能量如何升溫、做功、耗散與冷卻；3.7 則關心做功之後剩下什麼。一段語意被壓縮後，核心能量會進入主線，散亂部分會增加熵，但中間還有一種很微妙的剩餘物：它還沒成熟，卻不是全然無用。

用 3.6 的語言說，`Noise-AR` 可用自由能太低，適合分解；`Context-AR` 保留的是脈絡價值；`Structure-AR` 則仍然保有可用自由能，能在下一次換軸時重新做功。

所以 3.7 是從能量模型走向回收模型。它讓 3.0 不只會壓縮與展開，也能解釋為什麼某些被丟在旁邊的東西，後來會突然變成整個新分支的開頭。

Workflow

怎麼判斷一個渣渣值不值得回收

  1. 先收集不要急著刪。半成形比喻、沒放進正式文章的小問題、一直回來敲門的直覺，都先留下。
  2. 再分類它是 Noise-AR、Context-AR，還是 Structure-AR？先不用完美，只要判斷它還有沒有可用動力。
  3. 找弱動力它有沒有方向？能不能接到另一個領域？是不是能解釋某種一直卡住的現象？
  4. 換軸投影如果放進 1.0、2.0、3.0 或 4.0 的座標，會不會突然變得清楚？
  5. 孵化成頁當它有了命名、問題、模型、關係與用途，就可以從殘層升級成正式概念。

Formula Group

公式群

殘層分類

AR = Noise-AR + Context-AR + Structure-AR

殘層不是單一垃圾桶，而是需要拆開判斷的三種剩餘物。

殘層命運

Noise -> 分解 / Context -> 回收 / Structure -> 再生

不同殘層有不同命運。真正重要的是不要把結構殘層誤判成噪音。

壓縮循環

MDC -> AR -> RP -> 重力定位 -> S

多域壓縮後產生殘層，殘層經過反投影與重新定位後，可能形成新種子。

再生循環

S -> EDE 展開 -> 新模型 -> MDC

新模型展開後，又會成為下一次多域壓縮的材料。

Reading

渣渣理論真正保護的是未成熟的結構

這一頁不是要把所有碎片都神聖化。有些東西確實只是噪音，整理時可以放手。渣渣理論真正想保護的，是那些還沒有成熟、還沒有找到位置、卻隱約帶著下一個模型形狀的結構殘層。

因此 3.7 可以看成 3.0 通往 4.0 的最後一個接口。3.0 建立語意場，3.6 建立語意能量循環，3.7 補上殘層回收。到了 4.0，這些回收、再生與重新壓縮，就會更像完整的甜甜圈閉環。
