三光譜

三光譜把形成偏壓的差異拆成三條主軸：分化、存在、語法。六利則是這三條光譜兩端的功能化。

讀三光譜 下一篇：語意超導晶格 回 2.0

三光譜 = 偏壓後的差異，被分成三種處理方向。

Three Spectra

差異不是直接跳成六利，而是先長出三條主軸

三光譜補上了差異到六利中間最重要的一層。差異先形成偏壓，偏壓後的差異再沿著三種方向被處理：它如何拉開與受限，它如何變得有感與可保留，它如何被組織成語法與世界觀。

這三條主軸不是三個分類箱，而是三種處理方式。分化光譜處理差異如何被身體與邊界感到；存在光譜處理經驗如何變得有意義、有故事；語法光譜處理故事如何變成規則、位置、模型與 Meta 觀看。

當三條光譜各自出現發散端與收斂端，六利就不只是六個需求，而是三組張力對。2.0 因此開始把六利從分類表推成生成方程。

D / P / G

三條光譜

分化光譜

差異如何被感到、拉開、限制並推動事件。它接到生理利與生存利。

存在光譜

經驗如何變得有感、值得注意，並能被故事承接與保留。它接到意義利與敘事利。

語法光譜

故事如何沉澱成規則、位置、模型與世界觀。它接到社會利與認知利。

Working Formula

三光譜可以先讀成三組比例軸

分化率

D = Δ / π

生理利是發散端，生存利是收斂端；差異要能衝出，也要有邊界能承受。

存在率

P = ψ / φ

意義利讓經驗亮起來，敘事利讓它被承接、閉合與保留。

對齊率

G = η / Ω

社會利讓語法映射到群體，認知利讓語法被內部壓縮與理解。

母式

光譜率 = 發散端 / 收斂端

這是工作模型，不是數學定理；重點是看每條光譜如何靠兩端張力生成。
