小屁論 2.0 / 時間語法層

Snowball / Balloon / Knock

這三個詞描述對話與推論在時間中的相位：Snowball 負責累積，Knock 負責觸發選路，Balloon / Reset 負責壓縮回穩。

讀三態 語意超導晶格 回 2.0

Snowball / Knock / Balloon = 對話跨回合運作時的累積、觸發與壓縮重置。

Temporal Syntax

讓語意不要越跑越散

在 v2.2 裡，三態首先是 runtime 工具。它們不是在說 AI 真的有三個內部器官，而是在描述長對話如何累積、觸發、壓縮與重置。

Snowball 是累積：收集差異、整合語義、建立候選結構。Knock 是觸發：新的輸入敲門，決定要走哪條路。Balloon / Reset 是壓縮：把太大的語意泡泡收回基底，保留種子，避免失控擴張。

到了 3.0，這套語法可以被升級成語意場穩定性：Snowball 像收斂中的自我強化，Balloon 像擴散過強，Knock 像連續性中斷。因此它很適合放在 2.0 到 3.0 的橋上。

Three States

三個相位

Snowball

累積差異、整合語義、建立候選結構。順的時候會越滾越準。

Knock

外界輸入觸發路由，決定下一步回答或推論要往哪裡走。

Balloon / Reset

壓縮回基底狀態，更新偏好與摘要，避免語意泡泡失控膨脹。
