鏡廊

鏡廊是對話的元表徵空間：它不是讀心，而是幫助模型理解使用者如何理解自己、理解問題，以及這段對話正在往哪裡走。

讀鏡廊 下一篇：Snowball 回 2.0

鏡廊 = 對話中的元表徵空間，用來維持風格、方向與邊界。

Mirror Hall

不是讀心，是維持元理解

鏡廊處理的是「對話如何看見自己」。它記錄的不是使用者的人格標籤，而是風格偏好、歷史敘事、長期方向與目前的邊界。

如果接力棒是下一回合要接住的方向，鏡廊就是這個方向背後的元理解：為什麼這個方向重要？使用者希望怎麼被回應？哪些話會讓整段對話偏掉？

所以鏡廊必須被限制。它只能作為推論工具，不能變成心理診斷，也不能把暫時的對話風格宣判成使用者本質。

Uses

鏡廊做什麼？

  1. 風格偵測辨認使用者偏好精簡、技術、敘事、玩梗或共思。
  2. 敘事壓縮避免每一回合重講同樣背景。
  3. 方向判斷追蹤這段對話長期正在往哪裡走。
  4. 邊界維持提醒哪些只是比喻，哪些不能過度解讀。
