小屁論 1.0 起點專章

差異第一因

在性利論之前，小屁論更底層的起點是差異：如果沒有差異，就沒有相對、比較、觀測、投影，也沒有後來那個很胡鬧但很重要的「屁感」。

差異為第一因，是從「相對論」三個字往根部拆出來的。

Origin Story

從相對論拆到差異

差異第一因不是在重寫物理學的相對論，而是從「相對論」這三個字本身往下拆。

如果說一件事是相對的，代表它不是孤立成立，而是至少要有兩個位置、兩個狀態、兩個尺度，或兩個可以互相比較的東西。可是為什麼它們可以被比較？因為它們不完全一樣。再往前追，就是差異。

所以這裡的推論鏈很短，但很關鍵：相對，是因為有不一樣；不一樣，是因為有差異。差異不是某個物件的附屬性質，而是世界能被分辨、被關聯、被觀測、被運算的最低條件。

這也是為什麼差異比性利論更底層。性利論問的是「人為什麼會動」；差異第一因問的是「為什麼會有一個可被比較、可被判斷、可被行動的世界」。先有可分辨的差異，後面才會有感受、評價、利、選擇與行為。

  1. 相對論從名字本身開始拆，不直接等同正式物理理論。
  2. 相對相對成立，代表至少存在可以比較的兩端。
  3. 不一樣能比較，是因為兩端不是完全相同。
  4. 差異差異成為所有分辨、投影與生成的第一條件。

Working Definition

差異不是差別而已

可分辨

沒有差異，就沒有邊界、方向、強弱、前後，也沒有任何東西能從背景中被看見。

可比較

相對、大小、快慢、重要與不重要，都需要差異作為比較的最小條件。

可投影

主體能把世界投影成經驗，是因為世界先呈現出可被抓取的差異。

Butt Feeling

小屁論的屁感怎麼來

小屁論的「屁感」不是單純為了搞笑，而是從光屁股學長出來的表達方法。

差異第一因太像底層公理，聽起來容易變得嚴肅、抽象、甚至有點權威。可是小屁論的氣質剛好相反：它想把很大的問題脫掉包裝，露出可以被看見、被摸到、被討論的底層結構。

於是「光屁股學」出現了。光可以被理解成裸奔的差異：它不被過度包裝、不先套上神聖感，也不躲在漂亮名詞後面。當裸奔的差異被觀測到，它留下的可見外翻表面，就成了「小屁」的語法來源。

換句話說，小屁不是低級笑話的核心，而是一種去權威的理論姿勢：把世界、心智、行為與意義那些看起來很高大的東西，翻到一個最小、最可觀測、也最不裝的界面上。

所以小屁論的屁感，來自兩件事同時成立：一方面它在講差異、觀測、投影、利與生成；另一方面它故意不用莊嚴的語氣把自己包起來。它用很不正經的名字，保護一個其實很認真的問題：世界到底是怎麼被我們看見、評價，然後變成行動與意義的？

命名鏈

差異第一因 → 光屁股學 → 小屁論

底層是差異，語感外殼是光屁股學，最後穩定成小屁論這個名字。

屁感定義

小屁 = 差異被觀測後的外翻表面

它指的是世界或心智結構被看見時，露出來的最小可觀測界面。

Growth Chain

它怎麼接到後面的 1.0

  1. 差異世界先變得可分辨、可比較、可被觀測。
  2. 主體主體開始感受差異，並把差異轉成評價。
  3. 利差異進入生命與認知後，變成有利、不利、值得或不值得。
  4. 行為性利論、六利與交換率開始解釋人為什麼會動。

Reading Note

讀法備註

不是物理定理

這裡不是要替代物理學相對論，而是從「相對」這個語法直覺，拆出小屁論自己的起點。

不是單純玩笑

光屁股學與小屁感保留了反權威、去包裝、可讀化的語氣，但它們服務的是理論的表達方式。

接到性利論

差異回答世界為什麼可比較；性利論回答人在可比較的世界裡，為什麼開始追求主觀認知下的利。
