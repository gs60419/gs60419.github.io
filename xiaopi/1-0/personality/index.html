小屁論 1.0 行為專章

人格方程式

人格方程式把三價值、三熵、六利與交換率接起來，將人格暫時讀成一個人長期反覆形成的交換流程。

讀模型 回 1.0

人格 = 長期價值偏好 + 長期熵敏感 + 六利權重 + 交換率習慣

Personality Model

人格不是固定特質，而是長期交換流程

人格方程式適合放在小屁論 1.0。它的材料來自性利論、六利、交換率與熵成本這條人類行為線，而不是 5.0 的語法生命線。5.0 的自我函數在問「我如何成為我」，人格方程式則先問「一個人在差異與交換裡，長期會形成什麼習慣」。

這個模型不把人格看成固定標籤，也不想取代 MBTI、五大人格、九型人格或臨床心理學。它更像一個創作與自我整理用的工作台：觀察一個人遇到差異時怎麼估值、願意用什麼成本換什麼價值、哪一種熵最容易讓他卡住。

最短版本是：人格 = 長期價值偏好 + 長期熵敏感 + 六利權重 + 交換率習慣。更小屁一點，就是一個人最想賺哪種爽、最怕被收哪種稅，以及他習慣怎麼交換。

三價值描述一個人比較追求什麼：安全與穩定、關係與歸屬、影響與成就。三熵描述一個人比較怕什麼成本：風險混亂、關係摩擦、浪費低效。六利則是更深的權重盤，決定這些收益與成本對他到底有多重要。

所以人格不是一次事件，而是很多次交換留下的慢變量。短期事件造成微小偏移；微小偏移累積久了，就變成長期人格結構。某個人可能一次退縮只是情境反應，但如果他長期在高風險前都先退、先確認、先降熵，這就逐漸變成他的交換風格。

這套模型最適合用來問角色、自己或 AI 協作者：什麼東西會點亮他？什麼熵會讓他立刻退縮、爆炸或切斷？他用什麼方式降熵？靠秩序、靠關係、靠成果、靠理解、靠敘事，還是靠意義？

Formula

工作版公式

核心函數

P = F(V_pref, E_sense, L_weight, R_style)

P 是人格作為長期交換流程；四個變數分別是價值偏好、熵敏感、六利權重與交換率習慣。

小屁版本

人格 = argpattern(三價值 - 三熵, 六利權重, 交換率閾值)

argpattern 不是正式數學符號，只是表示一個人長期反覆選出的交換模式。

Reading Note

讀法備註

公式不是證明

這些式子目前是概念壓縮與工作模型，不是經過專業數學驗證的定理。

公式來源

我沒有數學專業與背景；若頁面或網站中出現公式，皆為 AI 推論與補充。

非診斷工具

人格方程式不是心理測驗、人格分類或臨床診斷，只適合當作交換動態的描述模型。

Layers

三層人格交換盤

收益層

三價值：安全、歸屬、影響，決定這件事給我什麼好處。

成本層

三熵：風險、摩擦、浪費，決定這件事會讓我付出什麼代價。

權重層

六利：生理、生存、意義、敘事、社會、認知，決定好處與代價有多重要。

Use Cases

適合拿來做什麼？

  1. 自我整理看自己被什麼點亮、被什麼卡住，以及習慣用什麼方式降熵。
  2. 角色設計讓角色的啟動、退縮、爆發與選擇有穩定內在邏輯。
  3. 遊戲設計轉成職業、卡牌、壓力條、資源轉換與角色互動規則。
  4. AI 協作調整 AI 的語氣、節奏、回應成本與長期互動風格。
