性利論公式化分支

利變思想實驗

這一頁整理性利論早期最有衝擊力的一條支線：把美、神聖、幽默、犧牲、殉道、道德與正義，轉成個體主觀認知下的利、利變與交換率語言。

看美感 看神聖 回性利論

這些公式不是數學定理，而是把個體主觀經驗壓縮成可討論語法的嘗試。

What This Means

不是把神祕感消滅，而是找它的生成條件

性利論的公式化分支，最早不是為了炫耀公式，而是為了解釋一個很難講清楚的問題：為什麼有些瞬間會讓人覺得美、覺得神聖、覺得世界忽然變大？

一般語言會說「這很美」、「這很神聖」、「這很感動」。性利論則往前追問：這些感受發生時，個體主觀認知下的利發生了什麼變化？世界模型被刷新多少？這個刷新是慢慢增加，還是瞬間跳升？它帶來的是正利，還是負利？

因此，這一組公式不應讀成專業數學，而應讀成一種壓縮語法。它把美感、崇高、幽默、道德與正義，暫時放進同一個工作台上，用「利的變化」與「交換率」來比較它們的結構。

Beauty

美：利的加速度

核心句

美 = d²L/dt² = 利的加速度

美不是靜止的好看，而是偏好權重在意識中忽然加速變化的一瞬間。

工作展開

美感 ≈ Δ利感 / Δt，在偏好臨界值上升時觸發閃擊

也就是當原本平穩的利感突然轉向、收束或暴增，個體就會感到驚艷、震動或被打開。

音樂

高潮、轉調、節奏斷點讓預期突然改變，情緒利感瞬間升高。

藝術

構圖、色塊、對稱破壞或視覺焦點轉移，使理解與感受同時跳階。

悲劇美

負利曲線中忽然出現信念、愛或尊嚴的上升拐點，於是痛感被轉成美感。

Sacred

神聖：超大量差異的正利交換

神聖體驗

神聖體驗 ≈ ΔΔ世界 × Δt^-1 × 利正↑↑

在極短時間內，世界模型被超大量差異刷新；但這個刷新不是負利的恐懼，而是正利的尊崇、敬畏、美與淚。

白話版

神聖 = Δ世界超大量 × 瞬間 × 正利

如果差異超大量但主觀利感轉負，會更接近恐懼或創傷；如果差異超大量且主觀利感轉正，就會接近神聖。

Humor / Sacred

幽默與神聖同構

  1. 幽默大差異、正利、瞬間同時成立，結果是笑。
  2. 神聖超大量差異、正利、瞬間同時成立，結果是神聖經驗。
  3. 笑到哭交換率高到超越語言，大腦用笑排放能量。
  4. 感動到哭交換率高到超越語言，大腦用淚排放崇高能量。

Sacrifice / Martyrdom

犧牲與殉道：高層利壓過生存利

犧牲

犧牲 = 高層利 - 眼前損失 > 0

當一個人把他人、群體、信念、承諾或長期意義算進自己的利，放棄眼前好處就不再只是吃虧，而是主觀系統裡更高利的選擇。

殉道

殉道 = 意義利 + 敘事利 + 社會利 > 生存利

殉道不是性利論的例外，而是極端版本：個體主觀認知中的價值、信仰或身份連續性，高到足以壓過肉體保存。

為愛犧牲

對方的安危被納入自己的主觀利，因此自己的損失可能被算成更高層的值得。

為群體承擔

個體把群體穩定、名譽、責任或未來合作性視為自己的高層利。

為信念赴死

信念不只是想法，而是個體主觀認知中維持自我一致與意義連續的核心利。

Boundary Cases

吸毒、自傷與自殺：模型的失靈區

這一類案例要和犧牲、殉道分開看。犧牲與殉道通常仍有高層利，例如信念、群體、愛、承諾或意義；但成癮、自傷與自殺傾向，常常更接近主觀利感系統被痛苦、病理或獎賞機制劫持後的失靈區。

從客觀角度看，嚴重成癮、自傷與自我毀滅行為很不經濟，甚至會損害生存、健康、關係與未來。但從個體當下的主觀認知來看，它可能被誤判成「立刻降低痛苦」、「暫時逃離現實」或「停止能量流失」的路徑。這不是健康的利，而是利感曲線被扭曲後的短路。

吸毒與成癮

可讀成獎賞系統被超常刺激劫持：短期正利被放大，長期生理利、社會利與敘事利被壓低或延後感知。

自傷

可讀成痛苦壓力下的錯誤調節：身體痛感被用來暫時換取心理痛苦的下降、存在感確認或情緒排放。

自殺傾向

可讀成極端痛苦中的停損誤判：當所有未來路徑都被主觀系統算成更耗能，消失可能被錯認為最低痛苦路徑。

成癮短路

成癮 = 短期正利↑↑ - 長期成本感知↓

它不是完整的利最大化，而是某個獎賞通道過度放大，使個體反覆選擇會傷害整體系統的短期回饋。

能量崩塌

自毀傾向 ≈ Δ負化 × 語法塌縮 × 投影反向

這是模型的警戒邊界：它說明性利論需要承認病理、失衡與認知扭曲，而不是把所有行為都美化成合理選擇。

Ethics

道德與正義的公式化旁支

道德

道德 = 長期合作策略。它不是天條，而是群體為了維持未來可合作性，逐漸內化成個體心理的交換規則。

正義

正義 = 長期群體運作的保險系統。它讓交換在群體尺度上維持穩定與可預期。

善惡

善可暫讀成多軸均衡；惡可暫讀成片利暴衝，某一軸膨脹並壓扁其他利。
