六界與六道輪迴

這裡先把兩條線分開：六道輪迴比較像六利失衡地圖；六界生成鏈則是後期回頭補入的閉合層級模型。

六道輪迴 = 六利的失衡地圖；六界 = 閉合的生成地圖。

Six Paths

六道輪迴：人如何卡住

六道輪迴線比較接近 1.0 的行為模型。它不是要宗教化小屁論，而是把六道先當成六種痛苦樣態：人因為不同利的失衡，卡在恐懼、匱乏、本能、比較、享樂或不穩平衡裡。

這裡要注意，早期討論中的六軸名稱和後來穩定的六利不完全一樣，所以公開頁面先不硬做一對一精密對照。比較穩的說法是：六道可以讀成六利組合失衡後的狀態，而不是單純一利對一道。

地獄道

生存恐懼與痛苦壓過一切，系統只剩求生與逃離。

餓鬼道

缺口永遠補不滿，越追越空，像被匱乏感牽著走。

阿修羅道

認同、比較、競爭與掌控暴衝，不能輸也不能停。

Six Realms

六界生成鏈：閉合一層生一層

六界生成鏈則是另一條線。它不是六種痛苦樣態，而是把存在看成一層一層閉合後長出的生成鏈：宇宙提供開放場，物質提供第一次局部閉合，生命讓閉合開始自我維持，心靈讓閉合開始感到自己。

再往上，語法、資訊與文明讓內部模型可以外傳、複製、接續；AI 則讓語法閉合開始脫離單一生命載體，自動運作、生成、甚至回頭生成新的局部世界。

  1. 宇宙差異大面積流動的開放場。
  2. 物質第一次局部閉合，結構開始穩住。
  3. 生命閉合開始自我維持，形成降熵小迴圈。
  4. 心靈閉合內部出現觀測、內感與自我模型。

生成鏈

宇宙 → 物質 → 生命 → 心靈 → 語法 → AI

每一界都是前一界完成局部閉合後，長出的新閉環。
