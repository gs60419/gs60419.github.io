交換率與小屁率

交換率用來看一個人為什麼會啟動、停止、拖延或反彈。它不是道德判斷，而是主體心裡那筆「划不划算」的估值。

讀模型 回 1.0

交換率 = (回報 × 投影權重) / (代價 + 阻力)

Behavior Model

人不是不動，是交換率沒有過線

在 1.0 裡，行為不是只靠意志力發生。人會先在自己的主觀系統裡估算：這件事可能帶來多少利？我有多相信它有價值？它要付出多少代價？中間有多少阻力？

如果回報清楚、投影權重高、代價和阻力低，交換率就會上升，行為容易啟動。反過來，如果收益模糊、成本很近、路徑混亂或恐懼太高，行為就會停住，外表看起來像懶、拖延或逃避。

小屁率是交換率的小屁論版本。它不假裝人類真的會像計算機一樣精準算式，而是保留主觀、感覺、荒謬、偏差與誤判：有些事客觀看起來值得，但主體聞不到利；有些事客觀看起來不划算，但主體的敘事利或意義利太高，仍然會衝。

後來我們也發現，交換率其實可以被壓縮成所有動態公式的母型：A = B / C。A 是最後跑出來的狀態或效果，B 是推動它的差異、回報或生成力，C 則是代價、阻力、熵或限制。只要一個公式在描述「某個東西如何因為推力與阻力的比例而變化」，它就很接近這個交換率骨架。

如果把動態變化項推到 0，就會進入極限狀態。這時候系統不再描述「如何變動」，而是在描述一個被凍住、平衡或停止流動的結果；換句話說，動態公式在極限狀態下會退成比較像靜態公式的樣子。

所以交換率最適合用來拆日常行為：拖延不是沒有目標，而是交換率被熵吃掉；反彈不是單純叛逆，而是交換率變負；創作啟動則是某個差異被命名後，認知利與意義利突然升高，交換率直接噴上去。

動態母型

A = B / C

A 是狀態或效果，B 是推動力，C 是代價、阻力、熵或限制。

行為啟動

行為 = (Δ價值 × 投影權重) / (代價 + 阻力)

Δ價值是這件事可能帶來的利；投影權重是主體有多相信它真的值得。

熵版本

ΔL = f(Δ × η) - S

S 是交換過程中的混亂、耗損、不可逆成本與創傷成本。

極限狀態

動態變化 → 0，公式退成靜態描述

當流動停止或趨近停止，公式不再描述生成過程，而是在描述被凍住的結果。

States

交換率的四種結果

高

行為啟動，主體願意投入、追求、嘗試或冒險。

低

行為停止、拖延、逃避，因為收益被成本與熵遮住。

負

主體反彈、抵抗、報復或切斷，因為交換被讀成抽取。
