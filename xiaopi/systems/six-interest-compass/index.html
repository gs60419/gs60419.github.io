六利數學羅盤

如果六利是一套語法，那麼羅盤就是它的讀法：同一張盤，讓你同時看見 差異、邊界、意義、敘事、社會與 Meta 認知是怎麼一圈一圈接起來的。

先看主環 回系統支線

六利數學羅盤不是最終定理，而是一張工作圖：它把三光譜、六利主環、 常數語法與 RT30 接面壓進同一個可讀結構。

Public Reading

這張盤到底在做什麼？

六利最容易讓人卡住的地方，是每一利都像一個抽象名詞。羅盤的工作就是把這些名詞 壓回生成流程：先有差異，再有生存邊界，經驗開始變得值得，值得的東西又會被補成故事， 故事再沉成規則，規則最後升成世界觀。

所以這張盤不是叫你背六個詞，而是讓你看見一個系統是在哪一段卡住、在哪一段過亮、 又該往哪裡接回去。

Core Ring

新版主環

主環順序

Δ → π → ψ → φ → η → Ω → Δ

這條環先看生成順序，不先看學科定義。它在回答：一個差異怎麼從被感到， 一路長成世界觀。

最短記法

差異 → 邊界 → 值得 → 故事 → 規則 → Meta

把六利先壓成一句人話，之後再往下讀表格與三光譜，就不容易迷路。

Three Spectra

三光譜怎麼掛進來？

Δ / π

分化光譜

差異先被感到，再被邊界收住。它在問：這個東西能不能活下來。

ψ / φ

存在光譜

經驗先變得值得，再被補成角色、記憶與故事。它在問：這個東西怎麼開始像它自己。

η / Ω

語法光譜

故事沉成規則，再升成 Meta 觀看。它在問：這個東西怎麼形成自己的世界。

Usage

拿這張盤可以做什麼？

讀一個人

看他最亮的是哪一利、最容易破的是哪一利、故事與世界觀在哪裡卡住。

讀一個作品

看它先抓差異、還是先抓世界觀；是靠情緒、敘事，還是靠制度與 Meta 來成立。

讀一套系統

看它是在感知層、邊界層、敘事層，還是社會與 Meta 層發生問題。

Bridge

這張盤之後會接到哪裡？

RT30

六利給軸，RT30 給幾何。羅盤是讀法，RT30 是載體。

108

角色、機體與勢力可以先用六利定核心，再用幾何與位階去排席位。
