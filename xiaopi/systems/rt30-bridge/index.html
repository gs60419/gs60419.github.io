RT30 × 六利

六利給這套系統方向，RT30 給它幾何位置。當兩者接起來之後， 理論才會從抽象名詞，長成可旋轉、可定位、可接線的盤。

看接線層次 回系統支線

最短讀法：六利是軸，十二極性是端點，1-9 是壓力位階，RT30 則是把這些東西放進同一個幾何載體。

Public Reading

這條橋到底在接什麼？

如果只有六利，我們知道自己在處理什麼問題；如果只有 RT30，我們知道一個結構可以怎麼被切面與定位。 兩者接起來之後，我們就不只知道「這是什麼」，還知道「它現在在哪裡」、「壓力走到哪一格」、 「應該往哪裡退、往哪裡進」。

所以這頁不是在證明 RT30 本身，而是在回答：當六利變成一張幾何盤之後， 它會怎麼支援角色設計、機體分類、魔法術式與世界建構。

Layer Map

從六利到 RT30 的五層接線

  1. Layer 1：六利本體 先確定你在處理哪種問題：差異、邊界、值得、故事、規則或 Meta。
  2. Layer 2：三光譜 把六利先壓成三組兩端，方便看生成、存在與語法三條主軸。
  3. Layer 3：十二極性 看這一利是成立中、外放中，還是缺失中、失衡中。
  4. Layer 4：RT30 幾何 把軸與端點投進可旋轉、可切面的立體載體。
  5. Layer 4.5：1-9 位階 補上目前壓力走到哪一格，以及過載時要往哪裡退。

Formula

最短操作式

軸

六利 = 你在處理哪種問題

它決定方向，不決定位階。

端點

十二極性 = 這個問題現在成立還是失衡

它決定這一軸是正向顯形，還是退向裂縫。

位階

1-9 = 這股壓力現在走到哪裡

它補上啟動、平台、過載、進位與鏡像修正。

幾何

RT30 = 讓這些東西能被定位、接面與旋轉

它把理論變成一個可以工作的盤。
