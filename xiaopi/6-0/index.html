從 π 到交換率的那一步

6.0 的入口是一個很小的問題：π 是不是周長除以直徑？真正重要的不是確認公式，而是發現 π 不是一個孤立的量，而是一個跨尺度保持穩定的比值。

當這個觀察接到小屁論原本的交換率時，6.0 的母公理就打開了：π = C / D，交換率 a = gain / cost。兩者都在說，系統真正穩定的常常不是單一數值，而是兩個量之間的關係。

於是比值語法開始往外長：在心智裡，它變成注意力、情緒與目標的曲率；在語言裡，它變成隱喻、敘事和壓縮；在 AI 裡，它變成模型如何生成方向與接口的問題。

Formula Layer

6.0 的核心公式感

幾何比值

π = C / D

圓的大小會變，但周長與直徑之間的比例保持穩定。這是 6.0 最乾淨的入口。

交換率

a = gain / cost

決策不是只看收益，也看收益與成本之間的比值。這讓心智選擇開始幾何化。

語法差異

φ = difference / scale

差異要放在尺度裡才有意義。φ 不是單純差多少，而是差異在某個世界裡有多重要。

系列展開

ratio -> closure -> imprint -> mind -> language -> route -> interface
