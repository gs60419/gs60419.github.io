小屁論 6.3 / Mind Ratio

心智系統比值化

6.3 把比值語法帶進心智層：注意力不是單純看見，情緒不是單純反應，目標也不是孤立命令；它們都可以被讀成心智場裡的比值曲率。

先讀這頁 看模型 回 6.0 系列

6.3 是比值語法進入心智調節機制的分支：心智如何用 φ 決定什麼重要、什麼靠近、什麼遠離。

Public Reading

心智不是平面，而是曲率場

在 6.3 裡，心智不是一張平坦清單，而是一個被差異、成本、收益、威脅、期待和目標彎曲的場。某件事之所以吸住注意力，不只是因為它很大，而是因為它在當下尺度中具有足夠高的比值。

這讓情緒和動機也能被語法化。害怕、期待、厭煩、好奇，都可以被看成心智曲率的不同形狀：它們改變路徑、改變距離感，也改變系統願意投入多少能量。

6.3 不直接處理語言與敘事，那是 6.4 的範圍。它比較像心智前處理層：先決定哪些差異被放大、哪些被壓低，語言之後才會把它們包裝成句子與故事。

Model

6.3 的模型骨架

注意力比值

attention = salience / background

注意力來自差異相對背景的突出程度。

情緒曲率

emotion = pressure / capacity

情緒不是只有強弱，也看壓力相對承載容量的比例。

目標吸引

goal = value / distance

目標越有價值、越可接近，心智場的吸引力越強。

心智 φ

φmind = change / tolerance

心智是否被改變，取決於變化量相對容忍尺度。
