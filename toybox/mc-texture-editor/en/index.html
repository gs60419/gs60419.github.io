📖 MC Texture Editor — Feature Guide

Welcome to MC Texture Editor!

📁 Loading a Texture Pack

  • Open Texture Pack Folder — Pick a local folder; all images appear in the left asset tree. Changes can be saved directly back to the files.
  • Open JAR (Writable) — Pick a Mod .jar file. After editing you can write changes back to the JAR without unpacking it.
  • Open .zip / .jar (Read-only) — Browse textures without write access; save via "Save As".
  • You can also drag & drop a folder or ZIP anywhere on the page.

🖼️ Start Editing

  • Click any PNG in the left asset tree to open it in the editor.
  • Use the 🔍 search box to filter assets by name.
  • Small thumbnails load lazily as you scroll.

💾 Saving

  • Save to file / Write to JAR — Overwrites the original (bottom floating bar).
  • Save As — Save as a new PNG anywhere on your disk.

🖌️ Drawing Tools

✏️
Brush (B)
Basic pixel drawing. Left-click uses the foreground color, right-click uses the background color. Supports 1–4 px brush sizes.
🌈
Variation Brush (V)
Each pixel picks a random color from the 5×5 gradient grid — great for natural-looking pixel textures.
🔆
Dodge/Burn (D)
Left-click brightens pixels by 10%; right-click darkens by 10%. Paint highlights and shadows directly.
🫧
Blend Brush (G)
Blends each painted pixel 30% toward the current background color for a soft-mixing effect.
⬜
Eraser (E)
Clears pixels to transparent. Supports all brush sizes.
🪣
Paint Bucket (F)
Flood-fills a connected region. Left-click = foreground, right-click = background.
💉
Eyedropper (I)
Click any pixel to set it as the foreground color. The color wheel updates instantly.
⬚
Rect Select (R)
Drag to select a rectangle. Then cut, copy, paste, flip, or rotate the selection.

📋 Layer System

Basic Operations

  • ＋ Add Layer — Inserts a new transparent layer on top.
  • － Delete Layer — Removes the active layer (minimum one layer required).
  • ⬇ Merge Down — Flattens the active layer onto the one below it.
  • Click a layer name to make it active.
  • Each layer has an independent visibility toggle and opacity slider.

📎 Cross-Asset Layers (copy a texture from another asset)

  • Right-click any asset in the left tree → "Copy as Layer".
  • The "📎 Paste as Layer" button in the bottom bar glows green.
  • Open your target asset, then click "Paste as Layer" to add the copied texture as a new independent layer.
  • Adjust opacity, merge, or paint on top of it freely.

Rect Select — Floating Layer

  • After selecting, a contextual toolbar appears: Cut / Copy / Paste / Delete / H-Flip / V-Flip / Rotate 90°.
  • Cutting or dragging the selection lifts it into a floating layer — move it freely.
  • Press ✓ Confirm or Enter to stamp it back down.

🎨 Color Palette

Hue Wheel + Saturation/Lightness Square

  • Outer ring — drag to pick the hue.
  • Inner square — X = saturation, Y = lightness; drag for precise color picking.
  • The hex code below the wheel shows the current color.

5×5 Gradient Grid

  • Center cell = current color (white border).
  • Horizontal: hue ±15° / ±30°.
  • Vertical: lightness ±10% / ±20%.
  • Click any cell to select it; works great with the Variation Brush.

MC Official Colors & Recent

  • Built-in swatches for Wool, Concrete, Wood, Stone, Ores, and Dye colors.
  • Recently used colors are auto-saved in localStorage across sessions.
  • Add custom colors; right-click a swatch to remove it.

⚙️ Advanced Features

⤢ Resize Canvas

  • Click the ⤢ button at the far right of the toolbar.
  • Quick Scale: ×2 / ×3 / ×4 / ×8 buttons auto-fill the new dimensions.
  • Pixel Perfect mode: automatically enabled for integer multiples — each original pixel expands to an exact N×N block with zero interpolation.
  • Extend: keeps original content; extra area is transparent; choose anchor from a 9-point grid.
  • Scale: stretches the image to fill the new size.
  • Crop: trims the canvas from the selected anchor direction.

⚙️ Batch Process

  • Load a texture pack, then click "⚙️ Batch Process" in the top bar.
  • Color Adjust: batch-adjust hue, saturation, brightness, contrast, opacity, and grayscale across the entire pack.
  • Color Replace: replace a source color with a target color, with a tolerance slider.
  • Rename: batch rename with prefix, suffix, find & replace, and auto-numbering.
  • Export: set scale and format, then download as a ZIP.

🧊 3D Preview

  • The right panel shows your texture on a block in real time.
  • Drag to rotate, scroll to zoom.
  • Switch shape: Full Cube / Slab / Flat Plane.
  • Toggle auto-rotate or reset the camera.
