📖 MC Texture Editor 功能說明

歡迎使用 MC Texture Editor！

📁 載入材質包

  • 開啟材質包資料夾 — 選取本機資料夾，所有圖片即時列出在左側樹狀結構，可直接存回原檔
  • 開啟 JAR（可寫回） — 選取 Mod 的 .jar 檔，編輯完可一鍵寫回 JAR，不需解壓縮
  • 開啟 .zip / .jar（唯讀） — 僅讀取，修改後需「另存新檔」
  • 也可以直接把資料夾或 ZIP 拖曳到網頁上載入

🖼️ 開始編輯

  • 在左側素材樹點一下任一 PNG 即可開啟編輯器
  • 可用 🔍 搜尋框過濾素材名稱
  • 素材旁的小縮圖會自動懶加載

💾 存檔

  • 存回原檔 / 寫回 JAR — 覆蓋原始檔案（底部浮動列）
  • 另存新檔 — 另存為新 PNG 到任意位置

🖌️ 繪圖工具一覽

✏️
筆刷 (B)
基本像素繪圖。左鍵用前景色，右鍵用背景色。支援 1–4px 筆刷大小。
🌈
變化筆刷 (V)
每筆從調色盤 5×5 漸層格隨機取色，畫出帶變化感的紋理。
🔆
提亮/調暗筆刷 (D)
左鍵畫過 → 像素亮度 +10%，右鍵畫過 → 亮度 -10%。適合做光影。
🫧
混色筆刷 (G)
把畫過的像素與目前背景色混合（30% 強度），做出漸融效果。
⬜
橡皮擦 (E)
清除像素變成透明。支援多種筆刷大小。
🪣
填色桶 (F)
填充連通區域。左鍵填前景色，右鍵填背景色。
💉
滴管 (I)
點擊畫布上的顏色，自動設為前景色並同步更新調色盤色相環。
⬚
矩形選取 (R)
拖曳框選區域，選好後可移動、剪下、複製、貼上、翻轉、旋轉。

📋 圖層系統

基本操作

  • ＋ 新增圖層 — 在最上方加入空白透明圖層
  • － 刪除圖層 — 刪除目前選中的圖層（至少保留一層）
  • ⬇ 合併 — 將目前圖層合併到下方圖層
  • 點擊圖層名稱可切換作用圖層
  • 每層都有獨立的顯示/隱藏（眼睛）與不透明度滑桿

📎 跨素材圖層（貼入其他素材的材質）

  • 在左側素材樹的素材上按右鍵 → 選「📎 複製材質為圖層」
  • 底部浮動列的「📎 貼入圖層」按鈕會亮起（綠色呼吸燈）
  • 切換到目標素材後，點「貼入圖層」即可把 A 素材的材質貼入 B 素材作為獨立圖層
  • 貼入後可調整不透明度、合併或繼續在上面繪圖

矩形選取工具的圖層操作

  • 拖曳框選後，出現選取工具列：剪下 / 複製 / 貼上 / 刪除 / 水平翻轉 / 垂直翻轉 / 旋轉 90°
  • 「剪下」或直接拖曳選區 → 內容變成浮動層，可自由移動位置
  • 按「✓ 確認」或 Enter 把浮動層蓋回圖層

🎨 調色盤

色相環 + 飽和度/明度方塊

  • 外圈圓環 — 拖曳選取色相
  • 內部方塊 — X 軸是飽和度，Y 軸是明度，拖曳精確取色
  • 色相環下方顯示目前顏色的 Hex 色碼

5×5 漸層格

  • 中心格 = 目前選中的顏色（白框標記）
  • 橫向 ±15° / ±30° 色相偏移
  • 縱向 ±10% / ±20% 明度偏移
  • 點擊任一格即可選色，搭配「變化筆刷」使用效果絕佳

MC 官方配色集 & 最近使用

  • 內建羊毛、混凝土、木材、石材、礦石、染料等 MC 標準色
  • 最近使用的顏色自動儲存（localStorage 跨重開仍保留）
  • 可加入自訂顏色（右鍵點色塊 → 移除）

⚙️ 進階功能

⤢ 調整畫布尺寸

  • 工具列最右側的 ⤢ 按鈕開啟對話框
  • 快速倍增：×2 / ×3 / ×4 / ×8 一鍵填入尺寸
  • 像素倍增模式：整數倍放大時自動啟用，每個原始像素精確擴展成 N×N 格，不插值不糊化
  • 延伸：保留原有內容，多餘區域透明，可選 9 點錨點決定原內容位置
  • 縮放：拉伸畫面填滿新尺寸
  • 裁切：從錨點方向裁掉超出部分

⚙️ 批次處理

  • 載入材質包後點頂部「⚙️ 批次處理」按鈕
  • 色彩調整：對整包素材批次調整色相、飽和度、亮度、對比、透明度、灰階
  • 色彩替換：指定來源色與目標色，支援容差值（0 = 精確符合）
  • 重新命名：批次重命名規則
  • 匯出設定：縮放比例，打包成 ZIP 下載

🧊 3D 預覽

  • 右側面板即時顯示材質貼在方塊上的效果
  • 拖曳旋轉視角、滾輪縮放
  • 可切換方塊形狀：完整方塊 / 半磚 / 平面
  • 自動旋轉切換 / 重置視角
